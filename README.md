# ChestCurioItems-Addons

你是否游玩过Chest Curio Items？如果没有，那么不妨去尝试一下！他是一个很有趣的饰品模组，但和同类模组不同的是他并没有依赖curios或者其他常见的api库，而是自维护了一套框架，这在游玩多模组的时候可能有一些割裂感，该附属则通过令其兼容curios的方式来尝试解决这个问题，该Git库不提供源码，仅存放成品jar文件

Have you played Chest Curio Items? If not, you should definitely give it a try! It is a very interesting accessories mod, but unlike similar mods, it doesn't rely on Curios or other common API libraries—instead, it maintains its own framework. This can cause a bit of a disconnected experience when playing with multiple mods. This addon attempts to solve the issue by making it compatible with Curios. Note that this Git repository does not provide source code; it only hosts the compiled jar files.
